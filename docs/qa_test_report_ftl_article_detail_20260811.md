## 4. 登录态交互状态反映（核心修复验证）

| 测试项 | 结果 | 说明 |
|--------|------|------|
| 详情API返回 isDigg/isCollect/isFollow | ✅ PASS | 网关重启后，详情 API 对登录用户正确返回 `isDigg=True isFollow=True`（此前为 false） |
| 页面加载呈现已赞/已关注 | ✅ PASS | 登录用户加载详情页，点赞按钮显示"已赞"、关注按钮显示"已关注"、点赞数≥1 |
| 公开只读接口 | ✅ PASS | detail/column/related/featured/recommend/comments 均返回 200 |

**根因与修复**：网关注入用户上下文仅对非公开路径生效，公开只读路径（如文章详情）虽有有效 accToken 也未注入 userId header，导致下游详情服务识别不到当前用户、`isDigg/isCollect/isFollow` 恒为 false。修复后的 `AuthorizeFilter` 对公开路径也解析有效 token 并注入 `userId`/`nickName` 头，无 token 或无效 token 则按匿名放行。修复后需**重建并重启网关**才生效（此前网关运行的是旧编译产物）。
