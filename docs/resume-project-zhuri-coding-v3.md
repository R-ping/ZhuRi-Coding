## 一、可直接粘贴版（主推 10 条）

**逐日 Coding｜Java 开发｜2024.06-2024.09**

**项目描述：** 面向程序员的内容社区与创作者变现平台（头条/掘金/知识付费综合），覆盖内容发布与 AI 审核、搜索索引、创作者激励与双等级成就、课程售卖与打赏、签到抽奖兑换、站内信 IM 完整闭环。后端按业务拆分为 user/content/search/reward/notification 五个微服务 + 统一网关，独立完成整体架构设计与 90%+ 核心模块。

**技术栈：** Java 17 · Spring Boot 3.3.4 · Spring Cloud Alibaba（Nacos/OpenFeign/Gateway）、MyBatis-Plus、MySQL 8（四业务库）、Redis + Redisson、Elasticsearch、PostgreSQL+pgvector 向量查重、阿里云 OSS 直传、阿里云百炼大模型 + 内容安全、支付宝沙箱、STOMP WebSocket、Zipkin/Prometheus

1. **双 Token 无感续期 + 多通道登录**：JWT Access(1h) + UUID Refresh(7d) 双 Token，刷新用 Redis Lua 原子"取即删"轮换 refresh_token，并发仅一人成功杜绝竞态；网关验签失败回 444 触发前端自动刷新重放，登出服务端吊销；网关与下游以 HMAC 内部签名互信、身份仅来自网关解析并注入，防伪造 userId 串号；手机验证码（登录即注册）/邮箱/微博、GitHub OAuth/公众号扫码多通道，BCrypt 存密，验证码发送限频防轰炸。
2. **内容发布→AI 审核→定时上线→搜索索引全链路**（核心一致性设计）：审核通过后经 Redisson 延迟队列按发布时刻调度；到点先落本地消息表（先落消息保证可补偿）→ 条件更新置文章 PUBLISHED → 同步 ES 索引（一步携带发布态，免二次更新）→ 完成即清理。消息表用**单 status 状态机**追踪：DB 置位失败态幂等自愈、ES 同步失败态由 20s 定时扫描重试（超限死信）；不引入 MQ，DB 与 ES 双写以"本地消息表 + 定时补偿"收敛最终一致。
3. **自研行为事件总线 + @Order 后置处理器责任链**：点赞/关注/发布等行为按类型路由，主操作落库后有序触发等级积分、文章热度、站内信通知、成就、用户统计等副作用，处理器独立降级互不拖垮；以"行为记录门控 + 唯一索引"双保险防重复加分/重复通知；文章热度用单条原子 SQL 重算（点赞×3+评论×3+收藏×6+浏览）消除读改写竞态。
4. **"逐友/逐力值"双等级体系与成就系统**：一个用户一行承载两套等级、共用 level_type 配置表；行为分值编码收敛为单一常量来源 + 运营配置表，逐友分明细/汇总双表支撑流水页；行为双通道加分（操作者逐日分、被赞者逐力值），悲观行锁防并发刷分，升级联动动态权限（授/收）与钻石奖励；成就勋章事件驱动实时判定（唯一索引 + 进度只增不减幂等），跨服务连续签到勋章查询时 Feign 兜底。
5. **大模型 AI 审核安全加固**：系统提示词与用户内容隔离、正则清洗 + UUID 动态分隔符防 Prompt 注入、顺从短语护栏；审核结果结构化输出解析（失败带原因重试）、图片内容安全审核，异常一律 fail-closed 拒放行；审核链按 @Order 编排（AI 文本/图片/RAG 相似度查重/质量分回馈），业务判定与可重试辅助环节分离，辅助环节指数退避重试（封顶 30s）、顶层兜底保证文章永不卡"审核中"；审核通过按 AI 质量分回馈作者成长值。
6. **课程支付与资损兜底**：金额全部服务端计算，支持折扣码与抽奖 5 折券；支付宝回调 RSA2 验签 + app_id + 金额一致多重校验后以条件更新幂等放权；Redisson 延迟队列超时自动关单，并对"支付成功但订单已关"自动退款（订单号幂等键防重复退，失败进重试任务）；7:3 月度结算（唯一索引防重结）。
7. **打赏与内容访问权限**：打赏限 1~10000 元、禁止自赏，支付成功联动经验值与站内信；课程章节按免费/试读/已购三级控制，未登录可试读，付费内容校验有效购买记录。
8. **三层限流组件**：网关按 IP 固定窗口限流（普通 600 次/分、登录等敏感 60 次/分，Redis 异常 fail-open 不拖垮链路）；自定义 @RateLimit 注解基于 Redis + Lua 滑动窗口，支持全局/IP/登录用户多维度同接口叠加、脚本 NOSCRIPT 自愈、可配降级方法；拦截器令牌桶兜底敏感接口，逐层拦截刷量与恶意请求。
9. **奖励中心**：签到连续天数 60 天窗口一次查库 + 内存回溯连续段（替代逐日多次查询），30 天周期阶梯奖励，Redis 分布式锁 + 唯一索引防重复签到，补签区间重算多退少补；抽奖概率权重 + 幸运值保底，实物奖品原子占用库存防超发（失败降级矿石）；福利兑换 Redis 预扣 + DB 乐观锁双防线防超卖，扣减失败库存/Redis/矿石三资源一致回滚。
10. **IM 与通知体系**：WebSocket 握手 JWT 鉴权 + 会话归属校验防越权拉取，陌生人消息按状态机限制发送频次；通知未读数以 DB 为唯一事实源、Redis 整包缓存失效重建，规避缓存不一致；评论通知仅审核通过后发送；网关-服务间 HMAC 内部签名 + 身份仅取网关透传，防伪造 userId 越权。

## 二、可替换的精简版（7 条，若简历篇幅紧张）

1. **双 Token 无感续期 + 多通道登录**：Redis Lua 原子轮换 refresh_token 防并发竞态，网关 444 驱动刷新重放、登出吊销；手机验证码/邮箱/OAuth/公众号扫码多通道，BCrypt 加密 + 发送限频；网关 HMAC 内部签名传递可信身份防伪造。
2. **内容发布→AI 审核→定时上线→搜索索引全链路**：Redisson 延迟队列调度；本地消息表单 status 状态机（先落消息→条件置位→同步 ES 一步带发布态），DB 置位失败自愈、ES 同步失败 20s 扫描重试、超限死信——无 MQ 的最终一致性。
3. **行为事件总线 + @Order 责任链**：一次行为有序触发积分/热度/通知/成就/统计，处理器独立降级；行为记录门控 + 唯一索引防重复，热度分单条原子 SQL 统一重算。
4. **双等级 + 成就体系**：单行双等级共用配置表、分值编码收敛单一来源、行为双通道加分、悲观行锁防刷；升级联动动态权限与钻石；成就事件驱动幂等解锁，跨服务签到勋章 Feign 兜底。
5. **大模型 AI 审核**：防 Prompt 注入三层防御 + 结构化输出重试 + fail-closed 策略；@Order 审核链含文本/图片/RAG 相似度/质量分回馈，可重试环节指数退避封顶 30s、顶层兜底永不卡审核中。
6. **课程支付资损兜底**：服务端计价 + 折扣/5折券；RSA2 验签与金额校验、条件更新幂等放权；延迟队列超时关单、支付成功已关单自动退款（幂等键）、7:3 月度结算与章节三级权限；打赏限额禁自赏联动经验与通知。
7. **限流 + 奖励中心 + IM**：三层限流（网关固定窗口 fail-open / @RateLimit Lua 滑动窗口多维叠加 / 令牌桶兜底）；签到/抽奖/兑换防刷防超卖体系；WebSocket 鉴权 + 陌生人状态机限频 + 通知未读 DB 唯一源。
