# 文章详情页与首页分栏留存优化设计

- 日期：2026-08-14
- 状态：已评审通过，待实现
- 方案：渐进打磨，分层交付（方案 A）

## 背景与目标

文章列表位于首页，是用户进入详情页的主要入口；详情页对产品留存十分关键。除文章质量外，首页各分栏与详情页的**动作交互、视觉效果**直接决定用户停留时长与回访。

本次优化以 **Web 端优先**，覆盖四个方向：

1. 详情页阅读体验
2. 详情页互动链路
3. 详情页留存闭环
4. 首页分栏体验

主场景为 **PC 浏览器**（移动端保证可用即可，不主动改动移动端布局）。

## 现状盘点

### 详情页（FTL 服务端渲染，`content/src/main/resources/templates/article.ftl` + `static/article-static.js`）

已具备：

- 顶部导航 + 登录弹窗（验证码/密码/社交）
- 作者信息区 + 关注按钮
- 点赞/收藏（正文区按钮 + 右侧悬浮操作栏）
- 评论（输入、表情、图片上传、点赞、回复、分页）
- 目录 TOC（桌面侧栏可收起、移动抽屉、滚动高亮）
- 为你推荐（正文下方）、相关推荐 / 精选内容（侧栏）
- 上一篇 / 下一篇
- 图片点击大图（lightbox）
- 打赏（tip）、收藏弹窗、举报弹窗
- 右侧悬浮操作栏：点赞 / 评论 / 收藏 / 分享 / 举报 / 沉浸

缺口 / 问题：

- **分享按钮无功能**（`sideShareBtn` 无 JS 处理，死按钮）
- **沉浸按钮无功能**（`sideImmersiveBtn` 无 JS 处理，死按钮）
- 无字号 / 行距调节
- 无阅读进度条
- 无暗色（夜间）模式
- 收藏弹窗确认、举报提交使用假 `alert`
- 无正文尾部作者卡片
- 无正文底部横排相关文章推荐
- 无回到顶部按钮

### 首页分栏（`src/pages/home`，Vue）

- 12 个分栏（推荐/关注/综合/后端/前端/Android/iOS/AI/开发工具/代码人生/阅读/排行榜）
- Web 端：顶部吸附分栏 + 平铺列表卡片，三种卡片类型 `article_0/1/3`
- 已具备：骨架屏、无限滚动、子分栏（推荐/最新）、标签筛选、作者悬浮卡、下拉刷新

可优化点：

- 分栏切换生硬，无过渡动画
- 信息流为平铺列表（底部 1px 分隔线），非卡片化视觉
- 图片无懒加载
- 无回到顶部按钮
- 刷新无「已更新 N 条」反馈

## 方案选择

用户已确认采用 **方案 A：渐进打磨，分层交付** —— 不改整体架构，按「感知强度」分层升级，每层独立可验证、可提交。

## 设计详情

### 阶段 1 · 详情页阅读体验

| 功能 | 设计 |
| --- | --- |
| 阅读进度条 | 顶部（顶栏下方 2px）固定细进度条，品牌色 `#1e80ff`，随窗口滚动实时更新宽度 |
| 字号 / 行距调节 | 正文区右上角 `Aa` 控件：A− / A+ 三档字号（小/标准/大）+ 行距三档（紧凑/标准/宽松）；CSS 变量实现，`localStorage` 持久化 |
| 暗色模式 | `body.dark` 类 + CSS 变量切换背景 / 正文 / 代码块 / 边框 / 卡片配色；与字号一并持久化 |
| 沉浸模式激活 | 激活后隐藏左右双栏、正文居中加宽、顶栏与悬浮栏淡出，专注阅读；再次点击退出 |
| 阅读设置面板 | 右侧悬浮栏新增 `Aa` 设置入口，弹出面板整合字号 / 行距 / 暗色 / 沉浸四项 |
| 图片大图 | 保留既有 lightbox |

### 阶段 2 · 详情页互动链路

| 功能 | 设计 |
| --- | --- |
| 分享面板 | 点击分享弹出面板：复制链接（Web 主路径）+ 微信 / 微博 / 掘金文案；`navigator.clipboard` + 降级方案 |
| 点赞 / 收藏动效 | 点击弹跳 / 缩放动画，数字平滑 +1/−1，图标填充过渡 |
| 收藏弹窗真实化 | 对接既有收藏集接口；确认收藏集后调用真实接口并提示，替换假 `alert` |
| 举报提交真实化 | 对接举报接口（如存在）；接口缺失则保持弹窗但改为服务端可调用方式 |
| 登录触点 | 未登录点击点赞/收藏/关注/评论 → toast「请先登录」+ 打开登录弹窗，统一引导 |

### 阶段 3 · 详情页留存闭环

| 功能 | 设计 |
| --- | --- |
| 正文尾部作者卡片 | 阅读完正文后展示：头像 / 昵称 / 简介 / 关注数 / 关注按钮 + 「查看作者主页」「该作者更多文章」 |
| 读完横排推荐 | 正文底部展示横排 3 张带封面「相关文章」；滚动到正文 85% 时预加载 |
| 回到顶部 | 右侧悬浮栏新增「回顶」按钮，平滑滚动 |
| 读完提示 | 滚动到底轻提示「— 已读完，感谢阅读 —」 |

### 阶段 4 · 首页分栏体验（Web 端）

| 功能 | 设计 |
| --- | --- |
| 分栏 Tab 过渡 | 激活态指示条平滑过渡动画；切换分栏内容淡入 200ms |
| 信息流卡片化 | 白底 + 圆角 8px + 轻阴影 + hover 轻微抬升；标题两行截断；作者行统一（头像 + 昵称 + 时间 + 阅读 / 点赞 / 评论数）；封面圆角 |
| 三种卡片统一 | 统一间距、圆角、字体节奏，仅保留布局差异（单图右图 / 纯文 / 多图） |
| 图片懒加载 | `loading="lazy"` + IntersectionObserver 兜底 |
| 回到顶部 | 列表滚动超一屏后右下角出现「回顶」悬浮按钮 |
| 刷新反馈 | Web 端刷新成功后顶部轻提示条「已更新 N 条新内容」 |

## 交付节奏

1. 阶段 1：详情页阅读体验
2. 阶段 2：详情页互动链路
3. 阶段 3：详情页留存闭环
4. 阶段 4：首页分栏体验

每阶段完成后可独立验证、提交；分阶段合并到 `feat/` 分支。

## 技术要点

- 详情页为 FTL 服务端渲染，改动集中在 `article.ftl`（结构 / 样式）与 `article-static.js`（交互），以及可能的后端接口（收藏集、举报、作者更多文章）——如接口缺失，先确认后端能力再实现，禁止假数据阻塞。
- 阅读设置用 CSS 变量 + `body` class 实现，避免大面积样式重写。
- 前端页面改动遵循现有组件与请求封装（`request.js` 等），不新增多余依赖。
- 全局规则：所有对外接口字段值不为 `null`；接口未就绪时前端 Mock 仅限过渡且对接后必须移除。

## 非目标

- 不做详情页 / 首页整体重构（不改架构、不拆 FTL 模块）。
- 移动端布局本次不主动改版，仅保证可用。
- 不新增埋点 / 数据统计能力。
